# NBA Simulator — Historical Teams

**Developer:** Hamdy Abou El Anein  
**Contact:** info@daylightlinux.ch  
**License:** GPL v3 (see LICENSE).

An entertainment-only Python 3/Tkinter simulator based on the project's historical 15-team Eastern and Western conference lists. Eight teams per conference are randomly selected for a fictional knockout tournament, followed by the NBA final. Results do not model real NBA standings or predict games.

```sh
python3 NBA.py
python3 NBA.py --text --seed 42
python3 -m unittest discover -s tests -v
```

Original EasyGUI code: [old branch](https://github.com/hamdyaea/NBA-Simulator-GUI/tree/old).
